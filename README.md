\# Flight Data Analysis using Hadoop



This project analyzes flight data using Hadoop, MapReduce, and Apache Pig.



\## Technologies Used



\- Hadoop

\- HDFS

\- MapReduce

\- Apache Pig

\- Java

\- CSV Dataset



\## Project Structure



\- Dataset - Flight dataset

\- MapReduce - MapReduce programs

\- Pig - Apache Pig scripts

\- Results - Analysis results



\## Analysis



The project includes analysis of:



\- Average delay by airline

\- Top 10 longest flights

\- Total flights by airline

\- Cancelled flights by airline

\- Delay causes

\- Diverted flights by airline

\- Flights by airline
